- **Introducing commit:** `9bfbf7d` ("Move tier discounts into a lookup table and add silver tier"), part of the 1.4.0 release (`f1812c8`).
- **Fix:** Added `["standard"] = 0.00m` to the table (smallest change restoring pre-1.4.0 behavior); applied via proposal `add-standard-tier-discount`.
- **Test result:** All 8 tests pass (was 3 failed / 5 passed before the fix).
